Capture what ordinary screenshots miss.

Universal Scrolling Screenshot captures webpages, dashboards, tables and nested scrollable regions that move vertically, horizontally, or in both directions. When table data is extractable, it can also export it to CSV or Excel.

Built for difficult scrolling layouts

The extension is designed for content that does not fit inside a single browser viewport.

2-D screenshots

Capture vertically and horizontally scrolling pages, grids and nested containers and stitch them into one output.

Table export

Export detected table data to CSV or Excel. The extension prefers direct data/framework access or complete DOM extraction before using scrolling reconstruction.

Stop & save

Stop a long screenshot or table extraction and save the usable data captured up to that point.

Native-resolution output

Avoid deliberate downscaling. Very large captures can use lossless SVG tile composition when a single browser canvas would be unsafe.

Virtualized grids

Designed to work with normal HTML tables and common virtual-grid patterns such as DataTables, Handsontable, SlickGrid and similar DOM-based grids.

Diagnostics

Selectable Error, Warn, Info, Debug and Trace logging records technical outcomes and failure reasons without intentionally logging table-cell contents or screenshot bytes.

Privacy by design

  • Screenshot processing happens locally in the browser.
  • CSV/XLSX generation happens locally in the browser.
  • No screenshots or table data are sent to the developer.
  • No advertising, tracking or analytics are built into Version 1.0.
  • Diagnostic logs are user-controlled and session-scoped unless explicitly downloaded.
