Release notes

Universal Scrolling Screenshot

Version 1.0

Initial public release.

Highlights

  • Full-page screenshot capture.
  • Vertical and horizontal two-dimensional capture.
  • Nested scroll-container selection.
  • Smart capture and manual Pick scroll area workflow.
  • Native-resolution stitching with lossless SVG fallback for exceptionally large captures.
  • Stop & Save for screenshot capture.
  • CSV and Excel table export.
  • Direct framework/data extraction where accessible.
  • Complete HTML-table extraction without scrolling.
  • Virtual-grid scanning fallback.
  • Stop & Save for partial table extraction.
  • Expected completion time for long operations.
  • Structured diagnostic logging with selectable severity levels and explicit success/failure reasons.

Privacy

Version Universal Scrolling Screenshot processes webpage content locally and does not transmit screenshots, table data, diagnostic logs or any other data to the developer.
