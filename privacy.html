Privacy Policy

Effective date: 26 August 2026
Developer/Publisher: Ramesh Babu
Contact: CyberArchon@outlook.com

Overview

Universal Scrolling Screenshot is a Chrome extension that lets users capture user-selected webpages and scrollable regions as screenshots and export detected web tables to CSV or Excel files.

The extension performs its capture, table extraction, file generation, and diagnostic processing locally in the user's browser. It does not send screenshots, extracted table data, diagnostic logs, or page contents to the developer or to third parties.

Information the extension processes

When the user explicitly invokes the extension, it may process content from the active browser tab that is necessary to provide the requested feature. Depending on the page, that content can include text, images, table values, page structure, and other website content. Website content may contain personal or sensitive information chosen or displayed by the website.

The extension may also process the active page's URL to operate on the selected tab. Diagnostic logging can retain a sanitized origin/path together with technical metadata such as capture dimensions, scroll positions, timings, component names, success/failure outcomes, reason codes, and error details.

Diagnostic logging intentionally omits screenshot image payloads and extracted table-cell payloads.

How information is used

Website content is used only to provide the extension's user-facing functions:

  • capture a user-selected page or scrollable region;
  • stitch screenshot tiles;
  • detect and extract table data;
  • generate CSV or Excel files;
  • provide progress and estimated completion time; and
  • diagnose capture/export failures when diagnostic logging is enabled.

Chrome Web Store Limited Use Compliance

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Information received from Chrome APIs is used only to provide or improve the extension's disclosed user-facing features and is not used for advertising, profiling, data resale, or unrelated purposes.

Storage and retention

Screenshots, CSV files, Excel files, and diagnostic JSON files are saved only when the user requests a download. Those downloaded files are then controlled by the user and the user's browser/operating system.

The selected diagnostic logging level is stored locally in Chrome extension storage so the preference can persist across browser restarts.

Diagnostic event entries are stored only for the current browser session so they can survive temporary popup closure during a capture or export. They are automatically discarded when the browser session ends, and the user can also clear them at any time from the extension popup.

Data sharing and transmission

The extension processes page content, screenshots, and extracted table data locally on the user’s device as needed to provide its functionality. This information is not transmitted to the developer, analytics providers, advertisers, or other third parties.

Because the extension does not collect or retain this information, no user data is sold or shared for advertising or other commercial purposes.

Remote code

The extension does not download or execute remotely hosted JavaScript or WebAssembly. Executable extension logic is included in the installed Chrome extension package.

Permissions

  • activeTab — temporary access to the active tab after user invocation.
  • scripting — runs bundled capture/extraction logic in the active tab.
  • downloads — saves files explicitly requested by the user.
  • storage — retains the logging preference and session-scoped diagnostic events.

The extension does not request persistent access to all websites.

User controls

Users can choose the diagnostic logging level, clear or download logs, stop an in-progress screenshot and save the captured portion, stop an in-progress table extraction and save collected data, and uninstall the extension to remove extension-managed local preferences.

Donations and external payment links

The extension website may provide an optional PayPal link for users who wish to support development. PayPal is a third-party service with its own terms and privacy practices. No PayPal payment information is processed by the Chrome extension or this static website.

Changes to this policy

If the extension's data practices materially change, this policy and applicable in-product/store disclosures will be updated before the changed practice is introduced.

For privacy questions or support requests, contact CyberArchon@outlook.com.
