Support

Troubleshooting, bug reports and feature requests.

Contact

Email: CyberArchon@outlook.com

Before reporting a problem

  1. Confirm you are using Universal Scrolling Screenshot Version 1.0.
  2. Reload the target webpage after installing or updating the extension.
  3. Retry with the exact scroll area selected using Pick scroll area.
  4. If the problem persists, enable Trace logging and reproduce it once.

What to include in a bug report

  • Chrome version and operating system.
  • Website URL, if it can be shared.
  • Whether you used Smart capture, Whole page, or Pick scroll area.
  • Whether the issue affects screenshot capture, CSV export, Excel export, or all of them.
  • The downloaded diagnostic JSON log.
  • A sample output image showing the problem, if it does not contain confidential data.
Privacy reminder: Do not send confidential screenshots, extracted tables, credentials, personal information, or other sensitive website content. Diagnostic logs are designed to omit screenshot payloads and table-cell payloads, but you should still review a file before sharing it.

Diagnostic logging levels

Off / Error / Warn

Minimal logging for normal use or basic failure reporting.

Info / Debug / Trace

Increasingly detailed operation diagnostics. Use Trace when reproducing a complex stitching or grid issue.

Feature requests

Feature requests are welcome at the same support email. Please explain the problem you are trying to solve and, where possible, provide a public test page that demonstrates the scrolling or table behavior.
